1. EXECUTIVE SUMMARY & PROJECT PURPOSE
--------------------------------------------------------------------------------
This project is an AI-powered Predictive Business Intelligence (BI) and Strategic
Decision Support System. It enables business leaders, analysts, and founders to:
  - Monitor key business metrics (Revenue, Profit, Churn Rate, CAC, CLV, etc.).
  - Predict whether their business is on a "Growing", "Stagnant", or "Declining" trajectory.
  - Understand WHY the model makes a prediction using Explainable AI (SHAP).
  - Forecast future revenue over upcoming months using Time-Series Machine Learning (Prophet).
  - Simulate "What-If" scenarios in real time (e.g., "What happens if I increase marketing spend by 20% and lower churn rate by 2%?").
  - Receive automated, actionable strategic recommendations tailored to current business health.
  - Chat with an embedded AI Business Advisor that answers strategic questions based on live company metrics.
  - Upload custom company CSV datasets with automated fuzzy column detection and dynamic ML analysis.

3. CORE MODULES & FEATURES EXPLAINED
--------------------------------------------------------------------------------

A. MACHINE LEARNING CORE (ml_core.py & ml_service.py)
   - Algorithm: XGBoost Classifier (XGBClassifier) trained and optimized using
     Scikit-Learn's RandomizedSearchCV.
   - Growth Label Formula:
     Growth Score = (0.35 * Revenue Growth) + (0.25 * Customer Growth)
                    + (0.20 * Profit Margin) - (0.20 * Churn Rate)
   - Labels:
     * Label 2 (Growing)  : Growth Score > 0.04
     * Label 1 (Stagnant) : 0.02 < Growth Score <= 0.04
     * Label 0 (Declining): Growth Score <= 0.02
   - Input Features (11 metrics):
     revenue_growth, customer_growth, profit_margin, churn_rate,
     marketing_spend, conversion_rate, aov, cac, clv,
     market_growth_rate, competitor_growth.

B. EXPLAINABLE AI ENGINE (SHAP)
   - Tool: SHAP (SHapley Additive exPlanations) TreeExplainer.
   - Purpose: Black-box ML models are hard to interpret. SHAP breaks down a
     prediction into individual feature contributions (e.g., "+15% due to high CLV",
     "-10% due to high churn rate").
   - Output: Rendered on the frontend as interactive SHAP feature importance charts.

C. TIME-SERIES REVENUE FORECASTING (forecasting.py)
   - Tool: Meta/Facebook Prophet.
   - Purpose: Takes historical monthly revenue data and fits a non-linear trend line
     with seasonality.
   - Output: Predicts future revenue points (`yhat`) along with 80% confidence interval
     upper (`yhat_upper`) and lower (`yhat_lower`) bounds for upcoming months.

D. STRATEGY RECOMMENDATION ENGINE (strategy_recommender.py)
   - Methodology: Multi-factor scoring algorithm.
   - Evaluates key financial ratios:
     * CLV to CAC Ratio (Target > 3.0)
     * Net Retention-Adjusted Growth (Revenue Growth - Churn Rate)
     * Market Share Lag (Industry Growth vs. Revenue Growth)
     * Paid Marketing Efficiency (Revenue Growth relative to Ad Spend)
   - Dynamically selects the highest-scoring business blueprint:
     1. Business Turnaround (Crisis mode for declining revenue / negative margin)
     2. Churn Reduction & Retention First (High customer churn)
     3. Margin Optimization (High revenue but poor profit margins)
     4. Marketing & Acquisition Scale-Up (Efficient CAC & strong CLV)
     5. Market Share Defense (Outpaced by competitor growth)
     6. Sustainable Scaled Expansion (Solid numbers across all indicators)

E. REAL-TIME WHAT-IF SIMULATION (WhatIfPage.jsx & scenario_engine.py)
   - Allows users to manipulate sliders for marketing spend, churn, CAC, pricing, etc.
   - Utilizes debounced API calls (500ms delay) to prevent backend spamming.
   - Immediately re-runs XGBoost + SHAP to show how target strategic decisions shift the business trajectory.

F. AI CHATBOT ADVISOR (chat_service.py)
   - Accepts user natural language queries (e.g., "How can I improve my profit margin?").
   - Pulls context from active live metrics, current strategy, and SHAP factors.
   - Supports LLM providers (OpenAI, Groq, local Ollama) with intelligent heuristic fallback if API keys are absent.

G. DYNAMIC USER DATA UPLOADER (UserDataPage.jsx & user_ml_service.py)
   - Allows users to upload custom CSV files.
   - Uses a fuzzy column matcher (matching aliases like `rev`, `sales`, `turnover`, `ad_spend`, `attrition`)
     to auto-map user columns to required ML model inputs.
   - Automatically computes missing features and executes the complete ML prediction + SHAP + Prophet pipeline.

5. DATA FLOW PIPELINE
--------------------------------------------------------------------------------
1. CSV Dataset / User Input / Slider Inputs
2. Data Preprocessing & Feature Derivation (Growth Ratios, Profit Margin)
3. XGBoost Model -> Predicts Trajectory (Growing / Stagnant / Declining)
4. SHAP Engine -> Calculates positive/negative influence per feature
5. Prophet Model -> Projects future 6-month revenue bounds
6. Recommender Engine -> Evaluates metrics against rule matrices & outputs advice
7. FastAPI Endpoint -> Packages JSON response payload
8. React Frontend -> Renders interactive visual dashboards (Charts, Metrics, Cards)

6. HOW TO RUN THE PROJECT LOCALLY
--------------------------------------------------------------------------------
Prerequisites: Python 3.10+, Node.js 18+

Step 1: Start the Backend API (Terminal 1)
------------------------------------------
  cd MY_PROJECT
  python -m uvicorn backend.main:app --host 0.0.0.0 --port 8000 --reload
  - Swagger Documentation: http://localhost:8000/docs
  - API Root: http://localhost:8000

Step 2: Start the Frontend UI (Terminal 2)
------------------------------------------
  cd MY_PROJECT/frontend
  npm run dev
  - Frontend Web UI: http://localhost:5173
